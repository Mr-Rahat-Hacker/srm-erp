# SRM ERP Frontend

The Angular application will be scaffolded in this directory in the next implementation step.

Planned frontend:
- Angular standalone components
- Feature areas: dashboard, suppliers, materials, sourcing and purchasing
- REST integration with the Spring Boot API under `/api/v1`
- Environment-based API URL configuration

From the repository root in Codespaces, create the Angular app here:

```bash
npx @angular/cli new . --directory . --routing --style=scss --standalone
```

Run it with:

```bash
npm start
```
