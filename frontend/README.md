# SRM Platform Frontend

Angular application for two authenticated experiences:

- Supplier Portal: registration, company profile, documents, invited RFQs, quotation submission and negotiation responses.
- Buyer / Approver Portal: supplier verification, qualification, RFQ creation, invitations, bid comparison, negotiation, approvals, award and reporting.

## First-release navigation (planned)

- Dashboard
- Suppliers
- Supplier Verification
- RFQ Management
- Supplier Invitations
- Quotations / Bids
- Bid Comparison
- Negotiations
- Approvals
- Awards
- Notifications
- Audit / Reports

Do not add Material Master creation, PR, PO, GRN, invoice verification, MRP or Schedule Agreement execution screens to the first-release SRM frontend.

Use Angular standalone components and route-level feature organization. Backend API base path: `/api/v1`.
